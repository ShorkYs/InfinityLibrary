# 3.0.0

Replaces active layout planning with bounded neighborhood constraint search while retaining saved room templates, overlapping doorway planes, topology/terrain safeguards, reservation recovery, decorations, Diversity and dead-end walls. Existing built layouts stay in their original world.

Adds optional Fabric 26.3 builder companion: colored area outlines, room browser/editor, all wand tools, settings and preview controls. Unifies wand clicks and adds staging undo/redo/cancel. Reading/shelf annotations can be captured in templates and transformed with generated rooms. Companion edits are permission/session/revision/template-version checked.

Adds native Book & Quill page editing for personal/shared manuscripts and automatic non-destructive stocking of loaded chiseled bookshelves.
